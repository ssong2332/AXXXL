# 자취 계약 내비 (가칭)

처음 자취하는 청년을 위한 계약·신고·지원 통합 타임라인 웹서비스.
계약 조건과 기본 정보를 넣으면 신고 의무, 신청해 볼 수 있는 지원, 할 일과 기한을 하나의 타임라인으로 안내한다.

- 이용 대상: 처음 자취방을 계약하는 만 19~39세 대학생·사회초년생
- 운영자: 공고를 등록·검수하는 관리자
- 첫 버전 범위: 서울 권역 공고

## 현재 상태

**데모 구현 중이다.** `demo/`에 계약·신고 화면(`demo/app.html`: 조건 입력, 자격 판정, 타임라인, 내 계약, 퇴거 준비, 서류함, 첫 실행 길잡이)과 계산 엔진(`demo/engine.js`)이 있다. 화면 6개에는 등장·진행 모션이 적용돼 있고, 첫 실행 길잡이(`#start`)는 단계 등장 모션을 쓴다. 이용 환경에서 움직임 줄이기를 켜면 모션은 꺼진다.

단위 테스트 (저장소 루트에서, Node 22): `node --test "tests/*.test.js"`

## 배경

- 서울시 전월세 안심계약 도움서비스: 상담은 시간·인력 제약이 있고, 계약 이후 신고·지원 신청·증빙 관리는 이어지지 않는다.
- 안심전세 앱: 계약 전 위험 확인에 집중하며, 이후 신고·지원 신청·증빙 보관은 안내하지 않는다.
- 청년 주거지원 자격은 다른 곳에서 따로 찾아야 한다.
- 계약 전~퇴거를 내 조건으로 잇는 서비스가 없어 이를 채운다. 위험 진단·상담은 기존 서비스로 연결한다.

## 주요 기능

필수

1. 계약 조건 입력 → 신고 의무·지원 자격 확인
2. 7단계 맞춤 타임라인 (계약 전·계약 당일·입주 준비·입주 당일·신고·정리·거주 중·만료·퇴거)
3. 운영자용 공고문 구조화·검수

선택

- ⓪ 계약 전 집 보기: 평수로 방 초안 생성, 2D·3D 보기, 현장 기록, 집 비교
- ④ 증빙 서류함·요건 점검
- ⑤ 기한 알림

## AI 활용 원칙

- 금액·자격 판정은 AI가 아니라 규칙으로만 한다.
- AI는 공고문 구조화, 체크리스트 문장 다듬기, 증빙 서류 점검에만 쓴다.
- 공고에서 추출한 내용은 운영자가 원문과 대조해 승인한 규칙만 이용자 판정에 반영한다.

## 사용 데이터

- 온통청년 청년정책 API (한국고용정보원)
- 서울시·자치구 청년 주거지원 공고 원문
- 전월세 신고제 기준 (국토교통부)
- 법정동코드 (행정표준코드관리시스템)
- LLM API

## 개인정보 원칙

- 입력한 계약 조건은 서버에 저장하지 않고 브라우저에서 계산한다.
- 체크 기록·서류는 이용자 기기에만 저장한다.
- 신분증은 보관하지 않는다.
- API·LLM 키는 서버 환경변수로만 관리하고 저장소에 넣지 않는다.

## 범위 제외

- 전세사기 위험 진단
- 신청 접수 대행
- 서울 외 지역
- 기관 시스템 연동
- 사진·영상 기반 자동 구조 복원
