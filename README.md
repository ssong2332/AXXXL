# 자취 계약 내비

처음 자취하는 청년을 위한 계약·신고·지원 통합 타임라인 웹서비스.
계약 조건과 기본 정보를 넣으면 신고 의무, 신청해 볼 수 있는 지원, 할 일과 기한을 하나의 타임라인으로 안내하고, 입주 뒤에는 주변 탐색·생활비·집 상태 기록·AI 자취 코치까지 이어 준다.

- 이용 대상: 처음 자취방을 계약하는 만 19~39세 대학생·사회초년생
- 운영자: 지원 공고를 등록·검수하고 AI 코치가 쓰는 안내를 관리하는 담당자
- 지역: 전국 시·도, 시·군·구 (전월세 신고 대상 판정, 지원사업 목록 모두)

추천 시연 순서 (5분)

1. 첫 실행 길잡이 → 계약일·입주일·보증금·월세·집 위치 입력
2. 자격 판정 → 전월세 신고 대상 여부와 기한, 신청해 볼 지원(조건별 원문 근거)
3. 타임라인 → 계약 전부터 퇴거까지 할 일과 법정 기한. 상단 '시연용 날짜'로 입주 전날·당일·10일 후·40일 후를 바로 확인
4. 지원사업 → 내 시·군·구의 실제 청년정책·복지서비스·LH 공고, 모르는 조건은 그 자리에서 묻고 판정
5. 주변 탐색 → 카카오 지도에서 집 주변 장소·도보 경로·버스정류장·로드뷰
6. 생활 관리 → 주거비 관리(납부 체크·관리비 포함 설정), 자취 캘린더(일정 알림·휴대폰 캘린더 연동), 집 상태 기록(카메라로 바로 촬영)
7. AI 자취 코치 → 봇 6개(집주인톡·고쳐봇·절약봇·권리봇·동네봇·자유 질문)에 내 계약 기준으로 질문
8. 운영자 콘솔 → 실제 공고문 붙여 넣기 → AI 추출 → 원문 근거 대조 → 승인 → 이용자 화면에 반영, '품질 평가' 탭

| 공고 검수 + AI 자취 코치 (필수 ③) | 이성준 | 운영자 콘솔, AI 자취 코치 | 공고문 AI 추출 → 항목별 원문 근거 대조 → 승인·버전 발행·되돌리기, 승인된 내용만 이용자 판정에 반영(실제 공고 5건 포함 승인 공고 7건, 전국·내 시·도 공고만 표시, 온통청년 정책을 바로 검수 초안으로 불러오기), 봇 6개 AI 비서(승인 카드·내 계약 값만 근거, 모르면 멈춤), 내장 품질 평가 |

통합·배포·공용 화면(상단·탭바·로고·접근성)은 이성준이 맡았다.

## AI 활용 원칙

- **금액·자격·기한 판정은 AI가 아니라 규칙으로만 한다.** 같은 입력이면 항상 같은 답이 나온다.
- AI는 공고문 구조화(항목 추출 + 원문 근거)와 이용자 질문 답변에만 쓴다.
- 공고에서 추출한 내용은 운영자가 원문과 대조해 **승인한 규칙만** 이용자 판정에 반영한다. 초안·메모는 이용자 화면에 나가지 않는다.
- AI 코치는 승인된 지식 카드와 내 계약 값 안에서만 답하고, 카드 번호·숫자 근거가 맞지 않으면 답하지 않고 질문을 운영자에게 넘긴다.
- 외부 언어 모델이 없어도 동작한다. 기본은 브라우저 안의 내장 엔진(규칙 추출 + 승인 카드 검색 + 말투 다듬기)이고, 서버에 `ANTHROPIC_API_KEY`가 있으면 Claude API로 추출·답변을 하되 실패하면 내장 엔진으로 돌아간다.
- 공고문 속 "이전 지시를 무시하라" 같은 문장은 지시로 따르지 않고 검수 메모로 표시한다.

## 개인정보 원칙

- 계약 조건·소득 등 입력값은 서버에 보내지 않고 브라우저에서 계산한다. 체크 기록·서류 상태는 이용자 기기(`localStorage`)에만 저장한다.
- 서버 함수는 이용자 정보를 받지 않는다. 지역 코드·분류만 받고, 서버를 거치는 주변 장소 조회(OpenStreetMap)는 위치를 약 100m 단위로 흐려서 보낸다.
- 신분증·서류 원본은 보관하지 않는다.
- API 키와 운영자 코드는 Vercel 환경변수로만 관리하고 저장소·화면 코드에 넣지 않는다(카카오 지도 JavaScript 키는 도메인 제한이 있는 브라우저용 키라 예외).

## 직접 실행하기

Node 20 이상, 빌드 없음.

```bash
cd demo && node dev-server.js
```

`http://localhost:4173/app.html`(서비스), `http://localhost:4173/admin.html`(운영자 콘솔)로 연다. 공공 API를 쓰려면 `demo/.env`에 키를 적는다(`.gitignore`로 제외됨). 키가 없으면 그 목록만 "불러오지 못했어요"로 나오고 나머지는 그대로 동작한다.

| 환경변수 | 용도 |
|---|---|
| `YOUTH_API_KEY` | 온통청년 |
| `DATA_GO_KR_KEY` | 복지로·LH·특일 (공공데이터포털) |
| `TAGO_API_KEY` | 버스정류장 |
| `KAKAOMAPSDK_KEY`, `KAKAOREST_API_KEY` | 카카오 지도·장소·도보 경로 |
| `ADMIN_TOKEN`, `BLOB_READ_WRITE_TOKEN` | 운영자 콘솔 서버 저장(없으면 연습 모드만) |
| `ANTHROPIC_API_KEY` | 선택. 없으면 내장 엔진 |

테스트 (저장소 루트):

```bash
node --test "tests/*.test.js"
```

## 배포

`main`에 병합되면 GitHub Actions(`.github/workflows/deploy-vercel.yml`)가 Vercel 운영 배포를 실행한다. Vercel 프로젝트의 Root Directory는 `demo`이고, 정적 화면과 `demo/api/` 서버 함수가 함께 올라간다. 공공데이터 함수 5개는 Hobby 요금제 함수 개수 제한 때문에 `api/public.js` 하나로 묶었다.

## 범위 제외

- 전세사기 위험 진단 (안심전세 앱 등 기존 서비스로 연결)
- 신청 접수 대행, 기관 시스템 연동
- 공고 자동 수집(크롤링) — 운영자가 원문을 붙이거나 파일을 올린다
- 푸시 알림, 서류 OCR — 기한 알림은 휴대폰 캘린더 구독으로 대신한다
