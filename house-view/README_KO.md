# 자취 계약 내비 · 집 보기 시연판

계약 전 집을 보러 다닐 때 쓰는 확장 기능의 **수동 시연판**이에요.
흐름: 평수로 시작 → 방 모양 수정 → 주방·가전·유리 분리문 배치 → 집별 사진·영상과 현장 기록 → 여러 집 비교

- 외부 AI·API 키·인터넷 없이 이 컴퓨터에서만 돌아가요.
- 사진·영상으로 방 구조를 자동으로 그리는 기능은 **없어요**. 사진·영상은 옆에 띄워 놓고 보는 참고 자료예요.
- 계약 추천, 안전 판정, 순위·점수는 만들지 않아요.

## 1. 필요한 프로그램

둘 중 하나만 있으면 돼요. 추가 설치(npm install 등)는 필요 없어요.

| 프로그램 | 버전 | 확인 방법 |
|---|---|---|
| Node.js (권장) | 18 이상 | `node -v` |
| Python | 3.8 이상 | `python --version` 또는 `py --version` |

브라우저는 최신 Chrome·Edge를 권장해요. 3D 보기는 WebGL이 켜져 있어야 해요.

## 2. 실행과 종료

### Windows
1. 압축을 푼 폴더에서 `START_WINDOWS.cmd`를 더블클릭해요.
2. 검은 창이 뜨고 브라우저가 `http://127.0.0.1:5180/`으로 열려요. 안 열리면 주소를 직접 입력해요.
3. **끄기:** 검은 창에서 `Ctrl+C`를 누르거나 창을 닫아요.

### 직접 명령으로 (모든 운영체제)
```
node server.mjs --open
```
Node가 없으면:
```
python server.py --open
```
- 다른 포트: `node server.mjs --port 5181`
- 끄기: 실행한 터미널에서 `Ctrl+C`

### macOS · Linux
`START_MAC.command`, `START_LINUX.sh`를 넣어 뒀지만 **이번에 실제로 실행해 보지 않았어요(미검증).** 위 "직접 명령으로"가 더 확실해요.

> `web/index.html`을 더블클릭해서 바로 열면 작동하지 않아요. 브라우저가 파일 주소(file://)에서 모듈을 막기 때문이에요. 꼭 위 서버로 열어 주세요.

## 3. 쓰는 법

| 단계 | 할 일 |
|---|---|
| 01 평수·방 모양 | 집 별명, 들은 면적(평/㎡), 면적 종류(전용·공급·실평수라고 들음·모름), 대상 범위(집 전체·방 하나·모름)를 넣고 **이 면적으로 초안 만들기**. 모양 후보(직사각형·길쭉한·ㄱ자·한쪽 들어간)를 고르고 꼭짓점을 끌어서 고쳐요. 벽을 눌러 **벽에 점 추가**, 꼭짓점을 골라 **점 삭제**, 화살표 버튼으로 10cm씩 이동. |
| 02 옵션 배치 | 냉장고·싱크대·인덕션·가스쿡탑·세탁기, 결합 주방(싱크대+쿡탑+쿡탑 아래 세탁기), 침대·책상·옷장, 유리 분리문을 놓고 끌어서 옮겨요. 회전(15°·90°), 크기(10cm씩), 삭제. 정확한 치수는 **상세 설정**에서. |
| 2D 편집 / 3D 보기 | 오른쪽 위에서 바꿔요. 3D는 끌어서 360° 회전, 휠·두 손가락·+/− 버튼으로 확대·축소, 오른쪽 끌기(또는 두 손가락)로 이동, **시점 초기화**, **벽 낮게**. |
| 03 사진·현장 기록 | 집별로 사진·영상을 골라 참고해요(선택). 수압·배수, 냄새·습기 흔적, 소음, 창 방향, 층·반지하 여부, 옵션 상태를 **확인함 / 의문 있음 / 확인 못 함**으로 표시. 물어볼 것·메모. |
| 04 집 비교 | 집들을 표로 나란히 봐요. 면적 기준이 다르면 경고가 떠요. |

- **되돌리기**: 면적·모양·물체 변경을 한 단계씩 되돌려요(글 메모는 대상 아님).
- **면적 유지**: 켜면 모양을 바꿔도 입력 면적에 맞춰 전체 크기를 다시 맞춰요. 계산상의 가정이지 실측 보정이 아니에요. 끄면 그린 도형의 면적을 따로 보여 줘요.
- 벽이 엇갈리는(자기 교차) 모양, 점 3개 미만, 너무 작은 면적은 저장하지 않고 이전 상태로 돌려요.
- 방 모양을 바꿔도 물체는 지우거나 옮기지 않아요. 방 밖으로 나간 물체는 경고로 알려 줘요.

## 4. 데이터 저장·삭제

- 작업 내용은 **브라우저 메모리에만** 있어요. 새로고침하거나 창을 닫으면 사라져요(고친 내용이 있으면 브라우저가 한 번 물어봐요).
- 상단 **JSON 저장**을 누르면 집 구조·물체·현장 체크·메모를 JSON 파일로 내려받아요. **사진·영상 파일은 들어가지 않아요.**
- **불러오기**: 이 시연판에서 저장한 JSON만 받아요(버전·형식·숫자·도형·항목·2MB 크기 검사). 잘못된 파일이면 지금 작업을 그대로 두고, 맞는 파일이면 바꾸기 전에 한 번 더 물어봐요. 불러온 뒤 사진·영상은 다시 골라야 해요.
- 사진·영상은 이 브라우저 안에서만 미리 보고 어디로도 보내지 않아요. 서버는 `127.0.0.1`에서만 열리고, 브라우저 보안 정책(CSP)으로 외부 접속을 막아 뒀어요.
- **얼굴·글자 자동 가림과 위치정보(EXIF) 제거는 하지 않아요.** 남의 집을 찍을 때는 먼저 허락을 받고, 얼굴·우편물·계약서·사진 액자가 찍히지 않게 해 주세요.
- 저장소(GitLab)에 실제 주소·사진·내보낸 JSON을 올리지 마세요. 샘플 2채는 가상 자료예요.

## 5. 폴더 구성

```
server.mjs            Node 로컬 서버(의존성 없음)
server.py             Python 대체 서버
START_*.cmd/.command/.sh  실행기
web/index.html        화면
web/styles.css
web/js/geometry.js    면적·도형·겹침 계산(규칙)
web/js/model.js       데이터 구조, 샘플, 물체 목록, JSON 검증
web/js/editor2d.js    2D 평면 편집(SVG)
web/js/view3d.js      3D 보기(three.js)
web/js/media.js       집별 사진·영상(메모리)
web/js/app.js         화면 제어
web/vendor/           three.js 0.170.0 (로컬 포함, MIT)
web/fonts/            Pretendard (SIL OFL 1.1, 라이선스 전문 PRETENDARD_LICENSE.txt)
tests/model.test.mjs  단위 테스트
QA.md                 검증 기록
```

## 6. 개발

- 단위 테스트: `npm test` (Node 18 이상, 설치 없이 실행)
- three.js 버전을 바꿀 때만: `npm install` → `npm run vendor` (`web/vendor`로 복사). 실행에는 `node_modules`가 필요 없어요.
- 3D 모듈은 3D 보기를 처음 누를 때만 불러와요.
- 외부 AI를 나중에 붙인다면: 사용자 전송 동의, 서버 쪽 비밀키(`config.example.env` 참고), 프런트엔드 코드에 키를 넣지 않기.

## 7. 알려진 제한

- 사진·영상 기반 구조 후보 추출, 콘센트·스위치 표식, 창 편집·햇빛, 건축물대장 대조, 운영자 규칙 승인, 실제 타임라인 연동은 없어요.
- 창·문 위치는 그리지 않아요. 3D의 벽 높이는 2.3m로 가정했어요.
- 물체 크기는 흔한 예시값이에요. 겹침·방 밖 경고는 참고용이고 설치·통행 가능 여부를 판정하지 않아요.
- 실제 휴대폰 터치, macOS·Linux 실행기, Safari·Firefox는 확인하지 않았어요(QA.md).
