# 검증 기록 — 집 보기 시연판 v0.1

- 검증일: 2026-11-01
- 환경: Windows 11 Home, Node 24.15.0, Python 3.12.10, Claude Desktop 내장 브라우저(Chromium 계열), Chrome 설치됨
- 판정 기준: 아래 "결과"는 실제로 실행한 것만 적었어요. 실행하지 않은 것은 마지막 "미검증"에 있어요.

## 검사 방식 구분

| 표시 | 뜻 |
|---|---|
| 실제 입력 | 브라우저 도구로 진짜 마우스 클릭·드래그를 보내고 결과 상태를 읽음 |
| 스크립트 클릭 | 화면의 실제 버튼·입력칸에 스크립트로 click/change 이벤트를 보냄(앱 코드 경로는 같음, 포인터 입력은 아님) |
| 자동 계산 | 단위 테스트 또는 페이지 안에서 수치 비교 |

## 4. 이번 검사에서 고친 결함

1. SVG 글자가 깨짐: 페이지 글자 간격(−0.15px)이 1단위=1m인 SVG에 그대로 적용됨 → SVG 안에서 0으로
2. 3D 전용 버튼이 2D에서도 보임: `.btn`의 display가 `hidden`을 덮음
3. 숫자 칸에 글자·빈 값을 넣으면 0으로 처리돼 크기가 3cm가 됨
4. 면적 종류·범위를 바꾸면 입력 중인 면적·단위가 사라짐
5. 시점 초기화 후 남은 관성 회전으로 시점이 다시 돌아감
6. 깊이를 줄이면 2D 세부 그림에 음수 크기(콘솔 오류)
7. 휴대폰에서 옵션 추가 후 배치 화면이 화면 밖에 남음
8. Python 서버: 폴더 요청 시 한글 오류 문구 때문에 연결이 끊김
