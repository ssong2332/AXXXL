# 시연용 정적 페이지

서버·빌드 없이 브라우저로 바로 여는 단일 HTML 시연판 두 개가 있다.

| 파일 | 내용 |
|---|---|
| `index.html` | 계약 전 흐름: 조건 입력 → 신고 의무·지원 자격 확인 → 타임라인, 방 크기 미리보기, 관리자 공고 검수 |
| `app.html` | 계약 후 서비스(새 디자인): 입주 준비·입주 당일·신고·거주·퇴거까지 관리 |

## app.html (계약 후)

| 해시 | 화면 | 내용 |
|---|---|---|
| `#home` | 홈 | 입주 D-day 카드, 오늘 할 일(입주 당일에는 순서형 체크리스트), 자취 여정 7단계, 다가오는 일정, 한 달 고정비, 지원사업 판정, 물어보기 |
| `#timeline` | 타임라인 | 계약 전 → 계약 당일 → 입주 준비 → 입주 당일 → 신고·정리 → 지원 신청 → 거주 중 → 만료·퇴거 |
| `#calendar` | 자취 캘린더 | 월세·관리비·공과금·지원금 입금 반복 설정, 낸 돈 체크, 기한 표시, `.ics` 내보내기 |
| `#support` | 지원사업 | 해당 가능·확인 필요·해당 안 됨 판정, 조건별 내 값, 제출 서류, 원문 링크·기준일 |
| `#area` | 우리 동네 미리보기 | 주변 시설 거리·도보 시간, 개략 지도, 카카오맵 로드뷰 링크, 데이터로 만든 요약, 현장 체크 |
| `#docs` | 서류함 | 서류 준비 상태 (이 기기에만 보관) |
| `#settings` | 계약 정보 | 계약일·입주일·금액 등을 바꾸면 모든 화면이 다시 계산됨 |

계산 규칙

- 기준일은 두 개다. 계약일(C)은 전월세 신고 30일, 입주일(M)은 전입신고 14일과 계약 기간의 기준이다. 기간은 첫날을 빼고 센다(민법 제157조).
- 전입신고는 대항력 때문에 입주 당일을 권장일로, 입주 후 14일을 법정 기한으로 따로 보여준다.
- 전월세 신고 대상이고 기한이 입주보다 뒤면 "전입신고 때 계약서를 함께 내면 신고·확정일자까지 한 번에"를 안내한다. 기한이 입주보다 앞이면 따로 신고하라고 경고한다.
- 지원 금액은 공고마다 따로 보여주고 합산하지 않는다. 캘린더의 지원금 입금은 이용자가 선정된 뒤 직접 켠다.
- 기한 알림은 서버 없이 `.ics` 파일로 휴대폰 캘린더에 넣는다(반복 일정은 RRULE, 알림은 VALARM).
- 물어보기는 승인된 규칙에서 만든 답만 근거와 함께 보여주고, 맞는 규칙이 없으면 답하지 않는다.
- 상단 "시연: 날짜 바꿔 보기"로 입주 전날·당일·10일 후 화면을 바로 확인할 수 있다.

## 시연판의 한계

- 지원 사업 금액·자격 조건과 관리자 화면의 "지난 공고" 변경 이력은 예시 값이다. 공고 원문과 대조 전이다.
- 동네 미리보기의 시설 위치·거리는 시연용 예시 좌표다. 로드뷰는 화면에 넣지 않고 카카오맵 공개 링크로 연다(화면 안에 넣으려면 카카오 지도 API 키와 도메인 등록이 필요).
- 알림 발송, 서류 OCR·요건 점검, LLM 공고 추출·답변은 동작하지 않고 규칙 기반 예시만 보여준다.
- 입력값과 체크 기록은 브라우저 `localStorage`에만 저장한다.
