# 시연용 정적 페이지

계획서 기준 화면 흐름을 확인하기 위한 단일 HTML 시연판이다. 서버·빌드 없이 `index.html`을 브라우저로 열면 동작한다.

## 들어 있는 화면

| 해시 | 화면 | 계획서 기능 |
|---|---|---|
| `#home` | 홈 | 첫 화면 |
| `#input` | 계약 조건 입력 (4단계) | 필수 ① |
| `#result` | 확인 결과 (신고 의무·지원 자격) | 필수 ① |
| `#timeline` | 6단계 타임라인·기한 알림 | 필수 ②, 선택 ⑤ |
| `#detail-rent`, `#detail-move` | 지원 상세 | 필수 ① 결과 |
| `#docs` | 증빙 서류함 | 선택 ④ |
| `#room` | 방 크기 미리보기 (CSS 3D) | 선택 ⓪ 시안 |
| `#admin` | 관리자 공고 검수 | 필수 ③ |

## 시연판의 한계

- 지원 사업 금액·자격 조건과 관리자 화면의 "지난 공고" 변경 이력은 예시 값이다. 공고 원문과 대조 전이다.
- 알림 발송, 서류 OCR·요건 점검, LLM 공고 추출은 동작하지 않고 안내 문구만 표시한다.
- 입력값과 체크 기록은 브라우저 `localStorage`에만 저장한다.
