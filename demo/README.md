# 시연용 정적 페이지

서버·빌드 없이 브라우저로 바로 여는 단일 HTML 시연판 두 개가 있다.

| 파일 | 내용 |
|---|---|
| `index.html` | 계약 전 흐름: 조건 입력 → 신고 의무·지원 자격 확인 → 타임라인, 방 크기 미리보기, 관리자 공고 검수 |
| `app.html` | 계약 후 서비스(새 디자인): 입주 준비·입주 당일·신고·거주·퇴거까지 관리 |

## app.html (계약 후 · 새 디자인)

메뉴는 다섯 묶음이다. 휴대폰에서는 아래 탭바(홈·내 주거·주변·생활·지원)와 묶음 안 하위 탭으로 이동한다.

| 묶음 | 해시 | 화면 | 내용 |
|---|---|---|---|
| 홈 | `#home` | 홈 | 인사 배너, 다음 할 일·이번 달 남은 납부·지원 요약, 우리 동네 탐색 지도, 근처 공공시설, 이번 주 가 볼 곳, 입주 한 달 챌린지 |
| 내 주거 관리 | `#contract` | 내 계약 | 계약 정보 입력·수정, 계산 결과, 시연용 날짜 |
| | `#timeline` | 타임라인 | 계약 전 → 계약 당일 → 입주 준비 → 입주 당일 → 신고·정리 → 지원 신청 → 거주 중 → 만료·퇴거 |
| | `#docs` | 서류함 | 서류 준비 상태 (이 기기에만 보관) |
| | `#moveout` | 퇴거 준비 | 갱신 통지 마감 등 중요한 날짜, 묵시적 갱신·계약갱신요구권·임차권등기명령 안내, 나가기 전 할 일 |
| 주변 탐색 (핵심) | `#map` | 지도 탐색 | 분류별 개략 지도, 장소 카드, 카카오맵 로드뷰·길찾기 링크, 가까운 순서 목록 |
| | `#recommend` | 주변 추천 | 공원·운동·공부·생활 편의·맛집·카페, 저장한 곳 |
| | `#infra` | 생활 인프라 | 교통·의료·안전·공공시설까지 도보 시간, 데이터로 만든 요약, 현장 체크 |
| 생활 관리 | `#spend` | 지출 관리 | 이번 달 고정비 구성, 낸 돈·남은 돈, 앞으로 6개월 |
| | `#calendar` | 공과금 & 납부 | 월세·관리비·공과금·지원금 입금 반복 설정, 납부 체크, `.ics` 내보내기 |
| | `#condition` | 집 상태 기록 | 입주 때·퇴거 때 방별 상태 기록, 집주인에게 보낼 문자 만들기 |
| 지원 & 상담 | `#support` | 지원사업 | 해당 가능·확인 필요·해당 안 됨 판정, 조건별 내 값, 제출 서류, 원문 링크·기준일 |
| | `#coach` | AI 자취 코치 | 승인된 규칙에서 만든 답만 근거와 함께, 맞는 규칙이 없으면 답하지 않음 |

상단 검색창은 주변 장소를 이름·분류·태그로 찾는다(예: 카페, 약국, 전입신고).

계산 규칙

- 기준일은 두 개다. 계약일(C)은 전월세 신고 30일, 입주일(M)은 전입신고 14일과 계약 기간의 기준이다. 기간은 첫날을 빼고 센다(민법 제157조).
- 전입신고는 대항력 때문에 입주 당일을 권장일로, 입주 후 14일을 법정 기한으로 따로 보여준다.
- 전월세 신고 대상이고 기한이 입주보다 뒤면 "전입신고 때 계약서를 함께 내면 신고·확정일자까지 한 번에"를 안내한다. 기한이 입주보다 앞이면 따로 신고하라고 경고한다.
- 지원 금액은 공고마다 따로 보여주고 합산하지 않는다. 캘린더의 지원금 입금은 이용자가 선정된 뒤 직접 켠다.
- 기한 알림은 서버 없이 `.ics` 파일로 휴대폰 캘린더에 넣는다(반복 일정은 RRULE, 알림은 VALARM).
- 물어보기는 승인된 규칙에서 만든 답만 근거와 함께 보여주고, 맞는 규칙이 없으면 답하지 않는다.
- 상단(휴대폰은 내 계약 화면)의 "시연용 날짜"로 입주 전날·당일·10일 후·40일 후 화면을 바로 확인할 수 있다.

## 시연판의 한계

- 지원 사업 금액·자격 조건과 관리자 화면의 "지난 공고" 변경 이력은 예시 값이다. 공고 원문과 대조 전이다.
- 주변 탐색의 장소·위치·거리는 시연용 예시 데이터다. 실제 가게가 아니며, 별점·리뷰는 만들지 않는다. 지도는 실제 지도가 아닌 개략도다. 로드뷰는 화면에 넣지 않고 카카오맵 공개 링크로 연다(화면 안에 넣으려면 카카오 지도 API 키와 도메인 등록이 필요).
- 알림 발송, 서류 OCR·요건 점검, LLM 공고 추출·답변은 동작하지 않고 규칙 기반 예시만 보여준다.
- 입력값과 체크 기록은 브라우저 `localStorage`에만 저장한다.

## 배포

`demo/` 폴더를 정적 사이트로 그대로 올리면 된다. `vercel.json`이 첫 주소(`/`)를 `app.html`로 보낸다. 빌드 과정은 없다.
