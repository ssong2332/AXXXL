# 자취 AI 비서 · 봇 프로필 이미지 프롬프트

지금 앱에 들어간 그림은 같은 폴더의 SVG(`landlord.svg` 등)입니다.
GPT 등으로 새로 뽑으면 **1024×1024 PNG**로 받아 아래 파일 이름으로 이 폴더에 넣고,
`app.html`의 `var BOT_IMG = 'svg';`를 `'png'`로 바꾸면 앱 전체(채팅방 목록·말풍선·버튼)에 반영됩니다.
`sw.js`의 SHELL 목록에 있는 `.svg`도 `.png`로 바꾸고 CACHE 버전을 올려 주세요.

## 공통 스타일 (모든 프롬프트 앞에 붙이기)

```
앱 프로필 아이콘. 정사각형 1:1, 모서리가 둥근 사각형 배경을 화면 가득 채움(여백 없음).
귀엽고 친근한 플랫 3D 클레이 느낌의 마스코트 캐릭터 하나만, 정면, 가운데.
동그란 검은 눈, 볼터치, 작은 미소. 굵고 단순한 형태라 36px로 줄여도 알아볼 수 있게.
배경은 부드러운 대각선 그라데이션 한 가지 색 계열. 글자·로고·워터마크·테두리 없음.
6개 아이콘이 한 세트로 보이도록 같은 조명과 같은 질감.
```

| `landlord.png` | 집주인톡 · 메시지 작성 | 하얀 작은 집 모양 캐릭터, 파란 지붕. 오른쪽 위에 점 세 개가 있는 파란 말풍선이 떠 있음. 배경은 연한 하늘색→파란색 그라데이션(#DDEBFF→#9EC3F5). 공손하게 메시지를 전해 주는 느낌. |
| `repair.png` | 고쳐봇 · 집수리 상담 | 하얀 네모 얼굴의 작은 로봇, 머리 위 주황 안테나, 양옆에 주황 귀. 한 손에 갈색 렌치를 들고 있음. 배경은 연한 살구색→주황 그라데이션(#FFE9D9→#FBB98A). 믿음직한 수리 기사 느낌. |

| `rights.png` | 권리봇 · 주거 권리 안내 | 하얀 방패 모양 캐릭터, 오른쪽 아래에 보라색 원 안의 흰 체크 표시. 배경은 연보라→보라 그라데이션(#ECEAFF→#A99FFF). 든든하게 지켜 주는 느낌. |
| `local.png` | 동네봇 · 주변 장소 추천 | 하얀 지도 핀(위치 마커) 모양 캐릭터, 주변에 점선으로 이어진 작은 보라 점 두 개(산책 경로). 배경은 연라벤더→라벤더 그라데이션(#F4ECFC→#CDB0EE). 동네를 안내하는 활발한 느낌. |
| `auto.png` | 자유 질문 · 그 외 모든 질문 | 노란 별 캐릭터, 오른쪽 위에 작은 흰 반짝임. 배경은 짙은 남색 그라데이션(#3A3F6B→#1B1E3A). 무엇이든 물어보면 알맞은 봇을 연결해 주는 똑똑한 느낌. |

1 집 모양(파랑, 말풍선) 2 로봇(주황, 렌치) 3 돼지 저금통(초록, ₩ 동전)
