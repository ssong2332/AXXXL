# PRD — 자취 계약 내비 (계약·신고 영역)

> 소유자: planner | 상태: 초안 | 최종 수정: 2026-11-11
> 상태는 초안/승인 두 가지. "승인"으로 바꾸는 것은 사용자만 한다 — 승인 전 구현 착수 금지 (AGENTS.md 파이프라인 규칙).
> **vibe 모드 문서 (2026-11-11 사용자 선택 "vibe 모드 (Recommended)")** — 메인 세션이 직접 작성. 범위는 박수홍 담당 "계약·신고"(계획서 필수 ①②)만이다.

## 한 줄 정의

서울에서 처음 자취하는 청년이 계약 조건을 한 번 넣으면, 꼭 해야 하는 신고와 신청해 볼 수 있는 지원, 기한이 붙은 할 일을 규칙으로 계산해 보여준다.

## 배경 / 문제

vibe 모드 — 생략 (계획서 "AI활용_공공서비스_직접개발_계획서_AXXXL_자취계약내비" 참조)

## 사용자

vibe 모드 — 생략

## 요구사항

### 기능 요구사항

| ID | 요구사항 | 우선순위 | 승인 기준 |
|---|---|---|---|
| F-01 | 조건 입력: 시·군·구(서울 25개), 보증금, 월세, 계약일, 계약 기간, 입주(전입) 예정일, 출생연월, 소득 구간(모름 포함), 무주택 여부(모름 포함), 유사 지원 수혜 여부(모름 포함) | 필수 | 저장한 값이 자격 판정·타임라인·내 계약·퇴거 준비 화면에서 같은 값으로 쓰인다 |
| F-02 | 전월세 신고 의무 판정 | 필수 | 보증금 6,000만 원 초과 또는 월세 30만 원 초과면 "대상", 기한 = 계약일 + 30일. 정확히 6,000만 / 30만은 "대상 아님" |
| F-03 | 지원 자격 판정 | 필수 | 지원마다 해당 가능 / 확인 필요 / 해당 안 됨, 조건별 내 값, 모집 상태(모집 중·마감·다음 공고 대기), 선정 방식, 원문 링크, 기준일을 표시. 지원 금액은 합산하지 않는다 |
| F-04 | 맞춤 타임라인 기한 계산 | 필수 | 전입신고 법정 기한 = 입주일 + 14일, 계약 만료 = 입주일 + 계약 기간 − 1일, 갱신 통지 마감 = 만료 2개월 전. 규칙에 없는 항목 0건 |
| F-05 | 퇴거 준비 날짜 | 필수 | F-04와 같은 계산 함수를 쓴다 |
| F-06 | 서류함 하나로 통합 | 권장 | 서류함 화면이 한 곳에만 있다 |

### 비기능 요구사항

| ID | 항목 | 기준값 |
|---|---|---|
| N-01 | 정확도 | 테스트 조건 30개 판정이 정답표와 100% 일치 (계획서 ① 기준) |
| N-02 | 개인정보 | 입력값은 브라우저 localStorage에만 저장, 외부 전송 0건 |
| N-03 | 근거 | 모든 판정 결과에 원문 링크·기준일 표시 |

## 화면

| 화면 | 목적 | 주요 상태 | 관련 요구사항 |
|---|---|---|---|
| 조건 입력 `app.html#input` | 계약 조건을 넣고 저장 | 빈 값: 기본 예시값 표시 / 잘못된 값: 필드 아래 안내 / 로딩·에러: 없음 — 서버 호출 없음 | F-01 |
| 자격 판정 `app.html#result` | 신고 의무와 지원 판정 확인 | 해당 지원 0건: "지금 조건으로 해당되는 지원이 없어요"와 신고 의무만 표시 / 모름 입력: "확인 필요" / 로딩·에러: 없음 — 계산만 함 | F-02, F-03 |
| 타임라인 `app.html#timeline` | 날짜순 할 일 체크 | 신고 대상 아님: 확정일자 항목으로 대체 / 지원 0건: 지원 신청 단계 숨김 | F-04 |
| 내 계약 `app.html#contract` | 계약 정보 확인·수정 | 기존과 같음 | F-01 |
| 퇴거 준비 `app.html#moveout` | 만료·통지 날짜 확인 | 만료 지남: "N일 지남" | F-05 |
| 서류함 `app.html#docs` | 서류 준비 상태 | 서류 0개: 필요한 서류 목록 표시 | F-06 |

## 범위 제외 (이번에 하지 않는 것)

- 지원사업 상세 화면·온통청년 API (주연서), 공고 검수·AI 코치 (이성준), 캘린더·지출·집 상태 (구민정), 주변 탐색·집 보기 (김동현)
- 서울 외 지역, 전세사기 위험 진단, 신청 대행

## 성공 기준

N-01 정답표 30개 100% 일치, F-04 기한 계산 테스트 전부 통과.
