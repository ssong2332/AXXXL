# 자취 계약 내비 · 시연 영상 기획서

녹화·음성(TTS) 담당 세션에 이 문서를 그대로 넘기면 됩니다.

## 1. 만들 것

| 항목 | 내용 |
|---|---|
| 길이 | **5분 이내** (목표 4분 40초, 넘으면 장면 사이 머무는 시간부터 줄이기) |
| 형식 | mp4, 1920×1080, 30fps, H.264 + AAC |
| 내용 | 운영 사이트를 실제로 조작하는 화면 + 한국어 내레이션(TTS) + 자막 |
| 주소 | https://jachwi-navi.vercel.app (소개: /intro, 운영자 콘솔: /admin.html) |
| 제출 | 유튜브 **일부 공개(비공개 링크)** 업로드 → 링크를 README에 추가 |

**톤:** 차분한 해요체, 또박또박. 한국어 여성 또는 남성 음성 하나로 통일하고, 속도는 기본~1.05배로 해요. 광고처럼 과장하지 않아요.

## 2. 녹화 전 준비

1. **시연용 계정:** 이메일로 회원가입을 미리 해 둬요. 인증 메일 링크까지 눌러 두고, **처음 입력(온보딩)은 하지 않은 상태**로 둬요.
   - 영상에서는 이 계정으로 로그인해서 온보딩부터 보여 줘요.
   - 카카오·구글 버튼은 보여 주기만 하고 누르지 않아요(외부 로그인 화면이 녹화에 들어가지 않게).
   - 이메일과 비밀번호는 문서나 영상 설명에 적지 않아요. 입력하는 장면에서 비밀번호는 점으로 가려져요.
2. **브라우저:** 새 시크릿 창(또는 새 프로필)을 써요. 예전 기록이 남아 있으면 화면이 달라져요.
   - 화면 크기는 1600×900 정도(16:9), 배율 100%로 해요.
   - 라이트 모드로 해요(앱 위쪽 반달 아이콘으로 바꿀 수 있어요).
3. **날짜:** 녹화하는 날 기준으로 **계약일 = 7일 전, 입주일 = 5일 뒤**로 넣어요. 그래야 "입주까지 5일", "다음 할 일", 신고 기한이 자연스럽게 보여요.
4. **다시 찍기:** 한 번 찍으면 계정에 기록이 남아 온보딩이 다시 안 나와요. 다시 찍을 때는 서버의 그 계정 기록을 지워야 해요(성준님이 개발 세션에 "시연 계정 기록 초기화"라고 하면 지워 줘요). 그다음 새 시크릿 창으로 시작해요.
5. **입력할 페르소나 "지우":**

| 칸 | 값 |
|---|---|
| 계약일 / 입주일 | 7일 전 / 5일 뒤 |
| 계약 기간 | 2년 |
| 보증금 / 월세 / 관리비 | 1000 / 45 / 7 (만 원) |
| 시·도 / 시·군·구 | 서울특별시 / 관악구 |
| 집 별칭 | 신림동 원룸 |
| 출생연월 | 2002-05 |
| 무주택인가요? | 예 |
| 비슷한 주거 지원을 받고 있나요? | 아니오 |
| 가구 소득 | 100% 초과 ~ 150% 이하 |
| 부를 이름 | 지우 |

## 3. 장면 구성 (12장면, 4분 40초 목표)

- **[화면]**은 그 장면에서 할 조작이에요. 버튼 이름은 화면에 보이는 글자 그대로예요.
- **[대사]**는 TTS로 읽을 문장이에요. 자막도 이 문장 그대로 써요.
- 장면 길이는 대사 길이에 맞춰요. 조작이 먼저 끝나면 그 화면에 잠깐 머물고, 로딩을 기다리는 구간은 편집에서 잘라 내요.
- 마우스 커서가 보이게 녹화하고, 클릭은 천천히 해요.

### S01 · 인트로 (0:00~0:22)
**[화면]** `/intro` 소개 페이지 첫 화면 → 천천히 아래로 내려 "8단계 길" 부분에서 잠깐 멈춤 → 다시 맨 위로
**[대사]** 처음 자취를 시작하면 계약서를 쓴 뒤에도 챙길 게 많아요. 전월세 신고, 전입신고, 확정일자, 지원금 신청까지 기한이 저마다 달라서 놓치기 쉽죠. 자취 계약 내비는 계약한 날부터 나가는 날까지, 할 일과 기한을 한 길로 정리해 주는 서비스예요.

### S02 · 로그인 (0:22~0:42)
**[화면]** "내 조건으로 시작하기" 클릭 → 로그인 화면에서 "카카오로 계속하기", "Google로 계속하기" 위에 커서만 올림 → 이메일·비밀번호 입력 → "로그인"
**[대사]** 시작하기를 누르면 로그인 화면이 나와요. 카카오, 구글, 이메일 중 편한 방법으로 로그인하면 기록이 내 계정에 저장돼서, 휴대폰을 바꿔도 이어서 볼 수 있어요.

### S03 · 처음 입력 4단계 (0:42~1:22)
**[화면]**
1. 계약일·입주일 입력 → "다음"
2. 보증금·월세·관리비 입력 → 아래에 "전월세 신고 대상이에요" 안내가 뜨면 잠깐 멈춤 → "다음"
3. 시·도 "서울특별시", 시·군·구 "관악구", 집 별칭 입력 → "다음"
4. 출생연월, 무주택 "예", 지원 "아니오", 가구 소득, 부를 이름 입력 → "내 자취 시작하기"

**[대사]** 처음에는 네 가지만 물어봐요. 계약일과 입주일, 보증금과 월세를 넣으면, 그 자리에서 전월세 신고 대상인지와 신고 기한을 알려 줘요. 다음으로 사는 지역을 고르고, 출생연월과 무주택 여부를 넣으면 받을 수 있는 청년 주거 지원까지 따져 봐요. 잘 모르는 항목은 모른다고 둬도 괜찮아요.

### S04 · 홈 (1:22~1:45)
**[화면]** 홈 화면 → 천천히 아래로: 다음 할 일 · 이번 달 낼 돈 · 신청해 볼 지원 → 이번 주 달력 → 우리 동네 지도
**[대사]** 홈에서는 입주까지 남은 날과 오늘 할 일, 이번 달에 낼 돈, 신청해 볼 수 있는 지원을 한눈에 볼 수 있어요. 휴대폰에서도 똑같이 쓸 수 있고, 홈 화면에 앱처럼 설치할 수도 있어요.

### S05 · 자격 판정 (1:45~2:12)
**[화면]** 왼쪽 메뉴 "자격 판정" → 위쪽 "전월세 신고 · 신고 대상" 카드에서 멈춤 → 아래로 내려 지원 카드 하나의 조건 목록(충족 / 확인 필요)과 "원문" 링크가 보이게
**[대사]** 자격 판정 화면이에요. 이 계약은 월세가 30만 원을 넘어서 전월세 신고 대상이고, 계약일부터 30일 안에 신고해야 해요. 지원 사업은 조건마다 충족과 확인 필요를 나눠 보여 주고, 근거가 된 법 조문과 공고 원문을 함께 달아 뒀어요.

### S06 · 타임라인 (2:12~2:37)
**[화면]** "타임라인" → 아래로 내리며 할 일 카드의 날짜 배지와 "근거 · 주민등록법…" 줄, "정부24에서 신고 ↗" 같은 버튼을 보여 줌 → 할 일 하나 체크("완료로 표시했어요")
**[대사]** 타임라인은 계약 전부터 퇴거까지 해야 할 일을 순서대로 보여 줘요. 할 일마다 법정 기한과 근거가 붙어 있고, 정부24나 인터넷등기소처럼 바로 처리할 수 있는 곳으로 이어져요. 끝낸 일은 체크해 두면 남은 일만 챙길 수 있어요.

### S07 · 지원사업 (2:37~3:02)
**[화면]** "지원사업" → 목록이 뜰 때까지 기다림 → 맨 위 "서울시 청년월세 지원" 클릭 → 상세(조건이 모두 맞아요 · 지원 내용 · 필요한 서류 · 신청하러 가기)
**[대사]** 지원사업 화면에서는 온통청년, 복지로, LH에서 내 시군구에 해당하는 실제 공고를 모아서 보여 줘요. 담당자가 공고 원문과 대조해서 승인한 공고는 조건별로 바로 판정하고, 아직 답하지 않은 조건은 그 자리에서 물어봐요.

### S08 · 주변 탐색 (3:02~3:25)
**[화면]** "지도 탐색" → 카카오 지도와 주변 목록 → "생활 인프라" → 지하철·버스·편의점·병원까지 도보 시간, 오른쪽 "밤길 안전" 카드
**[대사]** 주변 탐색에서는 카카오 지도로 집 근처 가게와 공공시설을 보여 줘요. 생활 인프라에서는 지하철, 버스, 편의점, 병원까지 실제로 걸어서 몇 분인지 알려 주고, 밤길 안전을 위해 집 근처 CCTV와 보안등 수도 확인할 수 있어요.

### S09 · 생활 관리 (3:25~3:50)
**[화면]** "주거비 관리" → 월세 줄의 "납부 체크" 클릭 → "자취 캘린더"(신고 기한과 일정이 달력에 표시) → "집 상태 기록"(괜찮아요 / 문제 있어요 / 사진)
**[대사]** 생활 관리에서는 월세와 공과금 납부를 체크하고, 자취 캘린더에서 신고 기한과 내 일정을 함께 관리해요. 입주할 때 집 상태를 사진으로 남겨 두면, 나중에 나갈 때 원상복구를 두고 다투는 일을 줄일 수 있어요.

### S10 · AI 자취 코치 (3:50~4:15)
**[화면]** "AI 자취 코치" → 봇 목록에서 "권리봇" → 입력칸에 "보증금을 못 돌려받으면 어떻게 해?" 입력 → 보내기 → 답변과 아래 "근거 · 주택임대차보호법…"이 보일 때까지 기다림
**[대사]** 궁금한 건 AI 자취 코치에게 물어보면 돼요. 집주인에게 보낼 문자, 고장 수리, 생활비, 권리, 동네 정보로 봇이 나뉘어 있어요. 답할 때마다 근거가 된 법 조문을 함께 보여 주고, 승인된 안내에 없는 내용은 지어내지 않아요.

### S11 · 운영자 콘솔 (4:15~4:33)
**[화면]** `/admin.html` → "코드 없이 연습 모드로 둘러보기" → "시연 공고로 해 보기"에서 공고 하나의 "이 공고 추출하기" → 추출 결과(항목마다 원문 문장 인용)와 오른쪽 원문 하이라이트
**[대사]** 이런 판정 규칙은 운영자 콘솔에서 관리해요. 공고문을 넣으면 AI가 나이, 소득, 기간 같은 신청 조건을 뽑고, 담당자가 원문 문장과 하나하나 대조해서 승인해야만 이용자 화면에 반영돼요.

### S12 · 마무리 (4:33~4:45)
**[화면]** 앱 홈으로 돌아와 잠깐 머묾 (또는 소개 페이지 마지막 "첫 자취, 길 잃지 않게 시작해요")
**[대사]** 집 위치와 사진, 서류는 내 기기에만 남고, 계약과 할 일 기록만 내 계정에 저장돼요. 첫 자취, 자취 계약 내비와 함께 길 잃지 않게 시작해 보세요.

## 4. 편집

- **자막:** 대사를 문장 단위로 나눠 화면 아래쪽에 넣어요(흰 글자, 반투명 검은 띠). 화면의 중요한 숫자를 가리지 않게 해요.
- **장면 전환:** 컷 또는 0.3초 페이드만 써요. 배경음악은 넣는다면 아주 작게 해요(대사보다 -20dB 이상).
- **강조(선택):** 숫자나 근거 줄을 짧게 확대하거나 테두리로 강조하면 좋아요(예: S05 "30일 안에 신고", S06 근거 줄, S10 법 조문).
- **확인할 것:**
  - 비밀번호가 보이지 않는지
  - 개인 이메일·실명이 화면에 길게 잡히지 않는지(계정 메뉴를 열지 않기)
  - 오류 알림이나 빈 화면이 없는지
  - 총 길이가 **5분을 넘지 않는지** (4분 40초 안팎이 좋아요)
